# Open3D Code Snippets

Open3D를 활용한 포인트 클라우드(Point Cloud) 처리 및 시각화를 위한 유틸리티 스크립트 모음입니다.

## 📁 파일 설명

### 포인트 클라우드 시각화

#### `pcd_viz.py`
- **기능**: 여러 PCD 파일을 서로 다른 색상으로 시각화
- **특징**:
  - matplotlib colormap(tab10)을 사용하여 각 파일별로 고유한 색상 부여
  - 여러 포인트 클라우드를 동시에 비교하기 편리
- **사용 예시**: 여러 시점의 포인트 클라우드를 한번에 확인

#### `pcd_viz2.py`
- **기능**: 두 개의 PCD 파일을 각각 회색과 초록색으로 시각화
- **특징**:
  - 두 개의 포인트 클라우드를 간단하게 비교
  - 색상 고정: PCD1 (회색), PCD2 (초록색)
- **사용 예시**: 두 포인트 클라우드의 차이점 비교

#### `pcd_viz2_offset.py`
- **기능**: 두 개의 PCD 파일을 Z축 오프셋을 적용하여 시각화
- **특징**:
  - Z축 방향으로 오프셋을 추가하여 수직 방향 비교 가능
  - PCD1 (회색), PCD2 (초록색 + Z축 오프셋)
- **사용 예시**: 높이가 다른 포인트 클라우드 비교

#### `o3d_frame_viewer.py`
- **기능**: 연속된 PCD 프레임을 비디오처럼 재생하는 뷰어
- **특징**:
  - 스페이스바로 재생/일시정지 제어
  - 거리 기반 colormap (viridis, jet 등) 지원
  - 인텐시티(intensity) 기반 색상 매핑
  - 거리 정규화 모드: percentile, log, gamma
  - 카메라 파라미터 저장/로딩 지원
  - 거리 및 인텐시티 분포 히스토그램 저장 기능
- **사용 예시**: LiDAR 센서로 수집한 시계열 포인트 클라우드 시각화

### 포인트 클라우드 편집 및 처리

#### `crop_points.py`
- **기능**: GUI를 사용하여 포인트 클라우드의 특정 영역을 대화형으로 크롭(자르기)
- **특징**:
  - Ctrl + 클릭으로 Bounding Box의 두 모서리 지점 선택
  - 실시간으로 포인트 크기, 색상 조절 가능
  - 크롭된 영역 미리보기 및 내보내기
  - 슬라이더와 색상 편집기를 통한 시각화 커스터마이징
- **사용 예시**: 관심 영역(ROI) 추출

#### `select_remove.py`
- **기능**: 포인트 클라우드에서 특정 점들을 선택하여 제거
- **특징**:
  - Shift + 클릭으로 제거할 점 선택
  - VisualizerWithEditing 사용
  - 선택된 점들을 제거한 후 새 파일로 저장
- **사용 예시**: 노이즈 포인트나 불필요한 객체 제거

#### `calc_distance_o3d.py`
- **기능**: 포인트 클라우드에서 선택한 점들 간의 거리 측정
- **특징**:
  - Shift + 클릭으로 여러 점 선택
  - 선택한 점들을 2개씩 쌍으로 묶어 거리 계산
  - 반복 측정 가능 (Enter로 재측정, 'q'로 종료)
  - 각 점의 좌표와 거리를 상세하게 출력
- **사용 예시**: 포인트 클라우드 내 객체 간 거리 측정

### 포인트 클라우드 병합

#### `pcd_merge.py`
- **기능**: 여러 PCD 파일을 하나로 병합
- **특징**:
  - 수동으로 지정한 PCD 파일 리스트 병합
  - 선택적 voxel downsampling 지원
  - 노멀(normal) 재계산 기능
  - 병합 결과 시각화 후 저장
- **사용 예시**: 특정 PCD 파일들을 선택적으로 병합

#### `pcd_merge2.py`
- **기능**: 디렉터리 내의 모든 PCD 파일을 자동으로 병합
- **특징**:
  - 디렉터리 경로만 지정하면 자동으로 PCD 파일 검색
  - 처음 5개 파일만 병합 (인덱스 제한 설정됨)
  - glob 패턴을 사용한 파일 검색
  - voxel downsampling 옵션
- **사용 예시**: 폴더 내 모든 PCD 자동 병합

#### `pcd_merge3.py`
- **기능**: 여러 PCD 파일을 평균화하여 병합
- **특징**:
  - 첫 번째 PCD를 기준으로 나머지 PCD에서 최근접 점 탐색
  - K-D Tree를 사용한 효율적인 최근접 이웃 검색
  - 각 점의 좌표를 평균 내어 노이즈 감소
  - 색상 정보도 평균화 가능 (주석 처리된 코드)
- **사용 예시**: 동일 장면의 여러 스캔을 평균화하여 노이즈 제거

### 정합(Registration)

#### `icp4.py`
- **기능**: ICP(Iterative Closest Point) 알고리즘을 사용한 포인트 클라우드 정합
- **특징**:
  - Point-to-Point ICP 구현
  - Point-to-Plane ICP 구현 (노멀 추정 포함)
  - 정합 결과 시각화 (소스: 빨강, 타겟: 초록)
  - 좌표축 프레임 표시로 변환 결과 확인
  - Fitness 및 RMSE 출력
- **사용 예시**: 두 포인트 클라우드 간의 변환 행렬 계산

### 카메라-LiDAR 캘리브레이션 및 투영

#### `hand_calibration.py`
- **기능**: 카메라-LiDAR 외부 파라미터(extrinsic)를 대화형으로 수동 조정하는 캘리브레이션 도구
- **특징**:
  - 키보드를 사용한 실시간 extrinsic 파라미터 조정
  - 쿼터니언 기반 회전 조정으로 짐벌락(gimbal lock) 방지
  - 평행이동(translation): q/a (X축), w/s (Y축), e/d (Z축)
  - 회전(rotation): r/f (roll), t/g (pitch), y/h (yaw)
  - X, Y, Z축 기반 컬러맵 시각화 지원
  - 실시간 투영 결과 확인 및 파라미터 출력
  - Ctrl+S로 조정된 extrinsic 저장
  - 조정 스텝 크기 변경 가능 (+/- 키)
  - 초기값으로 리셋 기능 (0 키)
- **사용 예시**: 카메라-LiDAR 캘리브레이션의 미세 조정 및 검증

#### `projection3.py`
- **기능**: LiDAR 포인트 클라우드를 카메라 이미지에 투영
- **특징**:
  - 내부 파라미터(intrinsic) 및 외부 파라미터(extrinsic) 사용
  - 상대 변환 행렬 지원
  - 왜곡 보정(distortion correction)
  - 거리 기반 colormap 적용 (TURBO colormap)
  - 투영 결과 이미지 저장
- **사용 예시**: LiDAR와 카메라 센서 융합, 캘리브레이션 검증

#### `utils.py`
- **기능**: 캘리브레이션 및 투영을 위한 유틸리티 함수 모음
- **주요 함수**:
  - `pcd_projection()`: 포인트 클라우드를 이미지에 투영하고 거리별 색상 적용
  - `perform_icp()`: ICP 정합 수행
  - `draw_contour()`: 체커보드 코너를 이미지에 투영
  - `filter_points_inside_chessboard()`: 체스보드 영역 내 포인트 필터링
  - `reprojection_error()`: 재투영 오차 계산
  - `joint_iou_loss()`: IoU 기반 손실 함수
  - `compute_iou()`: Convex Hull의 IoU 계산
  - `draw_iou()`: IoU 시각화
  - `plot_cost_history()`: 최적화 과정 시각화
- **사용 예시**: 카메라-LiDAR 캘리브레이션 최적화

## 🔧 의존성

주요 라이브러리:
- `open3d`: 포인트 클라우드 처리 및 시각화
- `numpy`: 수치 연산
- `opencv-python (cv2)`: 이미지 처리 및 투영
- `matplotlib`: 시각화 및 colormap
- `scipy`: 과학 계산 (Convex Hull, PCA)
- `scikit-learn`: 머신러닝 유틸리티 (PCA)
- `natsort`: 자연스러운 정렬

## 📝 사용 방법

각 스크립트는 독립적으로 실행 가능합니다. 스크립트 내부의 파일 경로를 수정하여 사용하세요.

```bash
# 예시: 포인트 클라우드 시각화
python pcd_viz.py

# 예시: 거리 측정
python calc_distance_o3d.py

# 예시: ICP 정합
python icp4.py
```

## ⚠️ 주의사항

- 대부분의 스크립트는 절대 경로를 사용하므로, 실행 전에 파일 경로를 수정해야 합니다.
- 일부 스크립트는 특정 하드웨어 설정(LiDAR, 카메라)에 맞춰져 있을 수 있습니다.
- GUI 기반 스크립트는 디스플레이가 필요합니다.
